# 계산 방법 (analyze.py)

기호: 전체 회차 수 n, 번호 i ∈ {1..45}, 한 회차에서 특정 번호가 나올 확률 p = 6/45 ≈ 0.1333.

## 1. 균일성 검정 — 카이제곱 적합도

- 관측 c_i = 번호 i 의 출현 횟수, 기대 E = n·p
- χ² = Σ (c_i − E)² / E, 자유도 44, p-값 = Q(22, χ²/2) (정규화 상부 불완전 감마)
- 전체 이력과 최근 R회 구간에 각각 적용한다.
- 해석: p ≥ 0.05 이면 "번호별 빈도 차이는 무작위 변동으로 충분히 설명된다". 지금까지 실제 데이터는 거의 항상 이 결과다.
- 참고: 한 회차 안의 6개는 비복원 추출이라 번호끼리 약한 음의 상관이 있어 검정이 약간 보수적이다. 결론에는 영향이 없다.

## 2. 최근 구간 z-점수

- 최근 R회 출현 횟수 r_i ~ Binomial(R, p)
- z_i = (r_i − R·p) / √(R·p·(1−p)), 양측 p-값 = erfc(|z|/√2)
- 번호 45개를 동시에 검정하므로 **본페로니 보정** 기준 0.05/45 ≈ 0.0011 을 쓴다. 이 기준을 넘는 번호가 없으면 "최근 강세"는 통계적으로 의미 있는 신호가 아니라는 뜻이다.

## 3. 지수가중 출현량 + 베이지안 수축 → 사후 출현확률

- 감쇠율 λ = 0.5^(1/H) (H = 반감기). 가장 최근 회차의 나이 = 0.
- 지수가중 출현량 e_i = Σ_d λ^age(d) · 1[i ∈ d], 유효 회차 수 m = Σ_d λ^age(d)
- 사전분포: 회차당 출현확률 ~ Beta(A·p, A·(1−p)), A = 사전강도(가상 회차 수)
- 사후평균 q_i = (A·p + e_i) / (A + m)
- lift_i = q_i / p (1보다 크면 최근 강세)
- 왜 수축하나: 몇 회 우연히 많이 나온 번호를 과대평가하지 않도록, 데이터가 적을수록 균등분포 쪽으로 끌어당긴다.

## 4. 추출 가중치

| 전략 | 가중치 w_i |
|---|---|
| hot | lift_i^K (K = sharpen) |
| mixed | 0.7 · lift_i^K / Σ lift^K + 0.3 · (gap_i + 1) / Σ(gap + 1) |
| uniform | 1 (비교 기준) |

- gap_i = 마지막 출현 이후 지난 회차 수. 무작위라면 gap ≥ g 일 확률은 (1−p)^g 이다(리포트의 "무작위 확률").
- K = 1 이면 사후확률을 그대로 쓰는데, lift 가 보통 0.8~1.3 범위라 균등추출과 거의 같다. K = 3(기본)이면 강세 번호가 눈에 띄게 자주 뽑힌다. K 는 표현 강도를 조절할 뿐 근거를 강하게 만들지는 않는다.

## 5. 조합 구조 필터

과거 당첨조합 전체에서 아래 분포를 구해, 흔한 범위를 벗어나는 조합을 제외한다.

| 항목 | 허용 범위 |
|---|---|
| 6개 합계 | 과거 합계의 5%~95% 분위 |
| 홀수 개수 | 과거 빈도 10% 이상인 값 |
| 22 이하 개수 | 과거 빈도 10% 이상인 값 |
| 최대 연속 번호 길이 | 누적 95%를 덮는 값 이하 |
| 한 구간(1-10, 11-20, 21-30, 31-40, 41-45)에 몰린 개수 | 누적 95%를 덮는 값 이하 |

리포트에 "과거 당첨조합 중 필터 통과 비율"을 함께 보여 준다(보통 60~70%). 필터는 당첨 확률을 바꾸지 않는다. 다만 사람들이 잘 안 고르는 "평범한 모양"의 조합을 만들기 때문에, 혹시 당첨되면 1등 당첨자가 적어 나눠 갖는 금액이 커질 수 있다는 정도의 의미만 있다.

## 6. 조합 생성

1. 가중치에 비례해 비복원으로 6개를 뽑는다.
2. 구조 필터를 통과하지 못하면 버린다.
3. 최소 포함 조건을 못 채우면 버린다. 강세 풀 = 최근 R회 출현 횟수 상위 10개(동률이면 lift 순), 미출현 풀 = gap 상위 6개. `--min-hot`, `--min-overdue` 로 게임당 최소 개수를 정한다. 가중치만으로는 확률 차이가 작아 사용자가 원한 성향이 조합에 안 드러날 수 있어서 둔 장치다.
4. 이미 뽑힌 게임과 4개 이상 겹치면 버린다(게임 간 다양성 확보).
5. 요청한 게임 수가 찰 때까지 반복한다(최대 50,000회 시도).
6. 시드 기본값 = 다음 회차 번호. 같은 데이터와 같은 시드면 결과가 같다.

## 7. 백테스트

- 최근 K회차 각각에 대해 *그 회차 이전 데이터만으로* 통계·필터·가중치를 다시 계산하고 S게임을 생성한 뒤, 실제 당첨번호와 몇 개가 일치했는지 센다.
- 같은 구조 필터를 쓰되 가중치와 최소 포함 조건이 없는 무작위 생성기를 비교 기준으로 함께 돌린다.
- 이론값(초기하분포): 평균 일치 개수 = 36/45 = 0.8, 3개 이상 일치 확률 ≈ 2.38%.
- 차이의 z = (평균_전략 − 평균_무작위) / √(SE₁² + SE₂²). |z| < 2 면 의미 있는 차이가 아니다.
